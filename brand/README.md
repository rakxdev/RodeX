# RodeX Brand — Mark Usage (locked 2026-08-09)

Mark: **PACKET-RETICLE-KEY** (concept R3-14). The mark is the folded instrument: packet diamond,
reticle seams, key-X, gold tab, red core.

## Files
| File | Use |
|---|---|
| `rodex-mark.svg` | Primary — full color (ink/gold/red), light & dark carbon surfaces |
| `rodex-mark-reversed.svg` | Reversed — gold on dark; foil/seal contexts |
| `rodex-mark-mono.svg` | Monochrome — single `currentColor`; print, stamps, favicons |

## Rules (researched best practice)
- **Clear space:** keep empty space ≥ the height of the gold tab on all sides.
- **Minimum size:** 32px height digital; never below 20px.
- **Don't:** stretch, rotate, recolor freely, add effects (glows/shadows), place on busy backgrounds.
- **Color roles:** gold = seals/reveals only · red = action/core only · amber = state only · ink = structure.
- **Wordmark:** RODEX DB — engineering mono, letterspaced, gold accent on the X (set in-app).
